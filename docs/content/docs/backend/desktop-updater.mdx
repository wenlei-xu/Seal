---
title: 桌面更新
description: Seal 桌面更新配置与发行边界
---

Seal 沿用本地签名更新机制，但默认更新地址与公钥为空。未配置时不展示更新按钮，不连接原产品的更新源。

发布前设置自己的 `BEEFTV_UPDATER_FEED_URL` 和 `BEEFTV_UPDATER_PUBLIC_KEY`，使用 `backend/cmd/update-release` 生成和验证签名清单。环境变量的历史命名保留用于构建兼容。

发行包使用 `Seal.app` 或 `Seal.exe`，随包 CLI 放在 `cli/seal` 或 `cli/seal.exe`，插件仍使用 `.beeftv-plugin` 格式。

新安装的默认数据目录为系统用户配置目录下的 `Seal`。如果已有 `BeefTV` 数据目录，继续使用该目录；更新不得搬迁、覆盖或删除工作区数据。

Windows 本地预览通过 `scripts/build-editing-preview.ps1` 构建。macOS 与正式 Windows 构建分别使用 `scripts/build-beeftv-release.sh` 和 `scripts/build-beeftv-windows-release.ps1`。尚未执行这些平台的正式发行验收。
