# 独立剪辑页布局

产品外壳由 `web/src/pages/edit/project.tsx` 管理工程、画幅、资产导入与可收起的助手。编辑页保留固定版本 HyperFrames Studio 的预览、选区、拖拽、文件写入、历史和导出能力。

`edit-host/studio-product.mjs` 对固定 `0.8.130` 浏览器包做内存中的结构转换，使用组件属性签名定位入口；匹配数量改变即明确失败，不猜测新版本，也不修改安装目录。自定义组件在同一 React、PlayerStore、Dock、文件与剪辑上下文中运行，避免第二份编辑状态。新增模块和样式通过运行包脚本一起打包。

`studio-product-client.js` 与 `studio-product.css` 管理素材类别、工具栏、轨道头和属性标签。轨道高度修改共享布局常量并刷新元素派生布局，时间尺、拖拽和行命中沿用相同坐标；波形比例调整真实视频内的声音条。锁定进入 Studio 的时间线编辑门禁，阻止拖拽、拆分和删除提交。锁定、名称、标记和显示偏好属于当前剪辑工程的本地界面配置。

独奏通过原生临时属性预览降低其他轨道音量，停止独奏时恢复，不改写工程源文件；导出前清除独奏。持久静音、速度和音量修改继续使用原生写入与撤销。标题与 SRT 字幕的添加使用所属网关事务和原生历史，不直接由外层网页写 HTML。

`scripts/verify-editor-layout.mjs` 在独立缓存工程中检查页面挂载、文字入轨、属性选区、真实轨道高度、波形档位、锁定、拆分与撤销。不会使用模型渠道或修改用户工程；截图与工作目录保存在 `.local/cache/editor-layout-smoke`。

图标使用与前端一致的 Lucide 标准节点，通过 `scripts/sync-edit-ui-resources.mjs` 从已安装、锁定版本生成本地资源，不加载远程图标。界面使用 Inter 直立无衬线字体，时间码使用 JetBrains Mono；中文使用操作系统无衬线字体。字体与图标许可随运行包保留。资源只服务所属 Studio 会话，不进入工程素材，也不覆盖预览内容中的字体。按钮提示复用 Studio 的浮层组件，禁用原因、保存状态与键盘焦点均显示；隐藏／静音／锁定按钮使用稳定组件身份，切换图标时保留焦点。

单片段拖入新轨道时，原版插入布局只按剩余片段压紧编号，导致原轨道一变空，新轨道又被排回第一条。产品转换共同调整插入编号、分区布局和行派生：保留编号之间的空行，已有轨道参与插入排序，新轨道通过原生批量移动、工程历史和网关事务持久化。空行由 `data-track-index` 的编号间隙恢复，不加入虚假片段，不修改视频画面；异常超过 4096 的编号不扩展为空行。`scripts/verify-editor-track-drop.mjs` 用缓存内的视频工程检查真实鼠标拖动、保存、重新打开和连续插入；双片段场景使用 `TRACK_DROP_TWO_CLIPS=1`。

导航和工程列表名称为“剪辑”。创作助手在编辑器右侧占用独立整列，覆盖整个工作区高度，关闭后编辑器恢复宽度；不再覆盖预览、属性或时间线。剪辑消息的 `@` 列表由所属工程的原生文件清单生成，只列图片、视频、音频，导入及工程版本变化后重新读取；已放入时间线的素材优先显示片段名称。引用形式 `@[media:相对路径]` 使用当前工程的编辑工具定位，不额外授予素材库访问权限。画布助手仍保留原有素材库引用。
