# Seal 品牌迁移

## 已实施

- 使用确认稿下方的白色趴卧海豹，导出 SVG、PNG、ICO 和小写 seal 字标；深色界面使用白色版，浅色界面使用反色版。
- 前后端默认外观、侧栏、画布菜单、启动画面、页面标题、桌面窗口与 Windows 产品信息统一为 Seal。
- 桌面快捷方式改为 Seal 创作工作台。构建脚本只嵌入当前前端产物，避免积累旧构建文件。
- 外部 Agent 的随包 CLI 和新生成 MCP 配置使用 seal 名称。已安装的外部客户端可在外部 Agent 页面重新复制配置。
- 新工作区不自动加入 BeefAPI；已有渠道和凭据保留。
- 取消原产品的推广及默认更新地址。没有配置自己的 HTTPS 地址和签名公钥时，更新器关闭；发布工作流要求明确配置自己的发布仓库和地址。
- README 与现行使用文档更新为 Seal。产品内显示 SEAL_CHANGELOG.md，上游历史 CHANGELOG.md 保留。
- 保留原 LICENSE 和作者版权，NOTICE 追加发行来源说明，许可证与第三方声明随桌面包分发。
- Windows 更新包校验改用可写文件句柄进行 Sync，修复只读句柄刷盘导致的权限错误。

## 兼容边界

仓库路径、Go 模块名、BEEFTV 环境变量、现有通信标识、插件后缀及工作区数据保持兼容。新安装使用 Seal 目录；已有 BeefTV 数据目录继续读取。第三方作者名称、历史证据和上游运行组件的来源链接保留。没有虚构 Seal 官网、GitHub 仓库或联系地址。

- 前端 TypeScript 检查与 Vite 构建通过；仍有原有大分包提示。
- 默认品牌迁移、保留自定义标识、全新渠道配置为空、旧渠道配置保留的专项测试通过。
- runtimeinfo 的 Seal 默认目录、旧目录保留与显式目录优先级检查通过。
- update-release 包装及签名配置检查通过；desktopupdate 测试通过。
- Windows 预览已编译，产品信息为 Seal，桌面窗口标题为 Seal，快捷方式指向新版启动脚本。

未执行付费模型调用、完整业务回归、macOS 发行构建或正式安装包签名。工程与素材的实际使用由用户在打开的桌面版验收。
